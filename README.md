# qa-playbook

A practical, lightweight QA playbook.  
This repository provides a universal bug report template that can be used across Jira, GitHub Issues, Redmine, and other tools.

## Contents
- `templates/bug-report.md`  
  └ Universal bug report template (English only)
- `templates/user-story.md`  
  └ Lightweight user story template for better requirement definition (English only)
